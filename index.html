End-to-End Encrypted Real-Time Communication System

Final Year Project

A real-time communication web application designed around client-side end-to-end encryption. The system provides real-time messaging through WebSockets and Django Channels while separating communication infrastructure from message encryption.

The project explores secure messaging concepts including forward secrecy, prekeys, the Signal Protocol and Double Ratchet concepts, together with a modern backend architecture.
